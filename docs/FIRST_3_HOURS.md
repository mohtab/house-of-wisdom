# First Session and the Next Three Hours

Version 0.2 concentrates production work on the first 35–45 minutes. Content beyond that point is a visible promise, not an implemented loop.

## Verified first-session pacing

| Milestone | Target | Current deterministic simulation |
| --- | ---: | ---: |
| First action | under 20 seconds | immediate |
| First reward | about 6–10 seconds | 6 seconds |
| Restore the desk | 3–5 minutes | 3.2 minutes |
| Unlock Mathematics | 7–10 minutes | 8.4 minutes |
| Make the first priority choice | 10–15 minutes | 12.2 minutes |
| Discover Al-Kindi | 25–35 minutes | 27.5 minutes |
| Complete Al-Kindi | 35–45 minutes including interaction | discovery occurs at 27.5; interaction time is player-paced |
| Restore the Scriptorium | natural session end | 37.9 minutes |

The simulation advances in one-second increments, automatically selects an efficient available activity, and uses the same production functions as the UI. It is a balance guardrail rather than a claim about every player.

## Opening flow

1. Show a neglected House, one damaged folio, and one action: Begin again.
2. Start a six-second Translation activity and expose Study navigation.
3. Reveal Research after the player has enough Knowledge to understand why it matters.
4. Restore the Keeper’s Desk and visibly improve the House.
5. Unlock Mathematics through Numerals in the Margins.
6. Ask the player to prioritize Translation or Mathematics.
7. Require both disciplines to reach Al-Kindi’s Patterns in Language.
8. Let the player apply a forgiving frequency-analysis method.
9. Add Method of Analysis to the Library and grant +10% Knowledge production.
10. Restore the Scriptorium and explicitly explain timestamp-based offline work.
11. Show Astronomy and Al-Battani only as future paths.

## Economy notes

- The first Translation task remains six seconds so the initial reward arrives quickly.
- Activity rewards use fractional internal values where needed; the UI keeps them readable to one decimal place.
- The desk costs 40 Knowledge, Mathematics 95, the first choice 55, Al-Kindi 330, and the Scriptorium 240.
- The first priority is exclusive during the first-session path so the decision changes the player’s efficient activity choice.
- Method of Analysis adds +10% Knowledge to every discipline and composes with discipline-specific research.

## Beyond the session

The Observatory, playable Astronomy, and Al-Battani’s complete Chronicle are deferred. Do not extend the three-hour arc until unmoderated v0.2 playtests show that new players understand and enjoy the first session without explanation.

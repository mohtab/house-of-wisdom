# v0.3 Art Set

The concept images establish composition, palette, character silhouette, environmental mood and interface direction. A separate static production set is integrated into the playable prologue. These assets still need a final human pixel-grid consistency pass before a release-quality animation pipeline.

| File | Use |

Production prompt direction: crisp 16-bit restoration mystery, alternate-history Abbasid Baghdad architecture, moonlit indigo ruin progressing to warm amber and turquoise, Najdi-inspired geometric restraint, readable silhouettes, no combat, modern objects, readable raster text, generic fantasy UI, or orientalist shorthand. Character cutouts were generated against a chroma field and converted to transparent PNGs; ghost opacity and the Ignorance effects are controlled in the interface.

## Files

### `v0.3-style-bible-concept-v1.png`

A combined visual language board containing:

- timeless researcher silhouette and action studies
- unidentified Al-Jahiz ghost
- ruined and partially restored cutaway hall
- core props and architectural materials
- Najdi-inspired border, textile and door motifs
- environmental darkness and connection-recovery studies

Prompt direction: 16-bit alternate-history Abbasid Baghdad restoration mystery; crisp limited-palette pixel art; moonlit indigo and dusty umber moving toward amber, turquoise, muted red and green; respectful regional synthesis; no humanoid enemies, combat, text or orientalist fantasy shorthand.

### `v0.3-opening-comic-concept-v1.png`

A silent four-panel prologue:

1. the researcher approaches the ruined House at dusk
2. moonlight reveals the hammer and torn manuscript
3. the unidentified ghost appears with fragmented speech
4. manuscript, hammer and lamplight establish the restoration promise

Prompt direction: preserve the style-bible character and architecture; use a clean 2 x 2 cinematic grid; move from indigo mystery toward amber hope; no captions, speech balloons, readable text, combat or modern objects.

### `v0.3-gameplay-screen-concept-v1.png`

A desktop gameplay composition demonstrating:

- the cutaway room as the visual focus
- compact resource and objective areas
- Al-Jahiz dialogue placement
- contextual restoration requirements
- bottom navigation
- blank HTML-text regions for real Arabic and English copy

Prompt direction: practical 16:9 browser-game interface embedded in a scholarly manuscript visual language; thin dark frames, parchment fields, turquoise and brick-red geometry, restrained brass; no generated readable text, glossy mobile-game UI or generic fantasy RPG HUD.

### `v0.3-character-sprite-concept-v1.png`

A character-production reference covering:

- researcher idle, short walk, reading, inspecting, repairing and carrying poses
- Al-Jahiz floating, speaking, pointing, amused and fading poses

Prompt direction: consistent 16-bit proportions and costume, dark production grid, clear small-scale silhouettes, work-hammer poses rather than combat, gender-open researcher and a warm, intelligent, faintly humorous Al-Jahiz.

## Production follow-up

Before integration:

1. approve or revise the character silhouettes and room perspective
2. lock the palette and sprite dimensions
3. redraw selected frames on a strict pixel grid
4. separate room layers, UI frames, icons and animation atlases
5. implement Arabic text as HTML/CSS rather than raster text
6. test every asset at desktop, tablet and mobile display sizes
